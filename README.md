# コメダ 使用期限検索アプリ

コメダ珈琲店の「標準使用期限一覧表」を、音声・テキストで品名検索できる社内向けウェブアプリです。

🔒 **社内関係者（店舗スタッフ）向けの資料です。店舗外への転載・共有はご遠慮ください。**
検索エンジンにインデックスされないよう `robots.txt` と `noindex` メタタグを設定していますが、
URLを直接知っている人はアクセスできる状態です。URLの共有範囲にはご注意ください。

## 使い方

このリポジトリをGitHub Pagesで公開し、`index.html` にスマホ・タブレットのブラウザでアクセスします。

- マイクボタンをタップ→「〇〇の使用期限」と話すと音声検索できます（`https`接続が必要です）
- テキスト入力でも検索できます
- 「一覧からさがす」でカテゴリ別に全品目を確認できます

## データの更新について

新しい「標準使用期限一覧表」PDFが発行された場合、`index.html` 内の `DATA` 配列を
PDFの内容と1件ずつ照合しながら更新してください（自動読み取りは精度上のリスクがあるため未実装です）。
